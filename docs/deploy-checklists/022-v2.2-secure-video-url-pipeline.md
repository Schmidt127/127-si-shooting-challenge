**Date:** 2026-08-24

**Lambda viewer:** `https://qzfaiyaq7a2cugh6alpov7iyfu0nrwbf.lambda-url.us-east-2.on.aws/file/{recordId}?token={token}`

## Root cause

Automation **022 v2.1** preferred `Reviewer File URL` but **fell back to `Canonical File URL`**, which is a **private direct S3 URL**. Parents opening that link received **AccessDenied XML**. Weekly emails (072) and video-feedback emails (073) could inherit the unsafe URL from Video Feedback writeback.

## What changed

| Component | Version | Change |
|-----------|---------|--------|
| **022** | v2.2 | Parent-facing `Video URL or Drive Link` uses **Reviewer/Lambda URL only**; never Canonical S3; repair note on `Upload Error` when missing |
| **072** | v4.8 | Weekly payload/HTML/text include **validated Lambda viewer URLs only**; `missingSecureUrlCount` diagnostic |
| **073** | v4.4 | Blocks parent handoff unless VF URL is **valid_lambda_viewer** |
| **Shared** | — | `lib/secure-video-url.js` validator (offline tests + weekly email contracts) |
| **Repair** | — | `repair-missing-reviewer-access-tokens.js` + `tools/airtable/repair_missing_reviewer_tokens.py` |

**Unchanged AWS posture:** S3 bucket stays private; no public `s3:GetObject`; Lambda viewer authorization unchanged; reviewer token lifetime unchanged.
