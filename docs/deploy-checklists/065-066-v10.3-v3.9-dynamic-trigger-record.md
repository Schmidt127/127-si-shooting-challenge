# Deploy checklist — 065 v10.3 / 066 v3.9 dynamic triggering recordId

**Date:** 2026-08-24  
**Repository branch:** `fix/065-066-dynamic-trigger-record`  
**Production impact:** Airtable automation script paste + input variable mapping (no schema changes)

## Problem

Production automations **065** and **066** were configured with a **literal test `recordId`** in the script action input instead of the **triggering record field**. Disposable fixtures could not run through the natural trigger path during WAS email QA (see `docs/testing/autonomous-qa/WAS_EMAIL_QA_20260824_FINAL_REPORT.md`).

GitHub scripts already read `input.config().recordId`; **v10.3 / v3.9** harden validation and document the required Airtable input mapping.

## Airtable input variable (critical)

After pasting each script, open the automation **Run script** action and set:

| Automation | Trigger table | Input name | Value (Airtable UI) |
|---|---|---|---|
| **065** | Homework Completions | `recordId` | **Record ID from trigger** (Homework Completions → Record ID) — **not** a pasted literal |
| **066** | Enrollments | `recordId` | **Record ID from trigger** (Enrollments → Record ID) — **not** a pasted literal |

Do **not** paste `recpuUEXGlVve9tRN`, `recCyFEPeATOVNlr9`, or any other fixed test ID into the input mapping.

## Production test steps

### 065 — reference Homework Completion

1. Open Homework Completion `recpuUEXGlVve9tRN` (HW1 reference).
2. Confirm `Homework XP Reconciliation Needed? = 1` (or toggle review fields per [`064-065-homework-review-test-card.md`](../testing/manual-test-cards/064-065-homework-review-test-card.md)).
3. Let automation run, or **Test automation** with the trigger record.
4. Expect exactly one XP Event: `HOMEWORK_XP|recpuUEXGlVve9tRN`, bucket **Homework Completion**, `Active? = true`.
5. Re-run — no duplicate XP Event (replay reuses same row).

### 065 — disposable Homework Completion

1. Create or use a disposable Homework Completion with valid Enrollment / Week / Submission / PHA links.
2. Trigger 065 via formula (`Homework XP Reconciliation Needed? = 1`).
3. Expect `HOMEWORK_XP|{that HC record ID}` — source key must match the **triggering** HC, not a reference fixture.

### 066 — reference Enrollment

1. Open Enrollment `recCyFEPeATOVNlr9`.
2. Check **Run Shot Milestone Check?**.
3. Expect milestone unlocks only for crossed thresholds; `Run Shot Milestone Check?` clears on success.
4. Re-check — no duplicate unlock rows for the same `SHOT_MILESTONE|{enrollmentId}|{milestoneId}` keys.

### 066 — disposable Enrollment

1. Use a disposable active Enrollment with Grade Band, Program Instance, and counted submissions.
2. Check **Run Shot Milestone Check?**.
3. Unlocks must use that Enrollment's record ID in every `Milestone Source Key`.

### Negative — invalid input (manual script test only)

| Input | Expected |
|---|---|
| Missing `recordId` | Error: `Missing input variable: recordId` |
| `recordId` not starting with `rec` | Error: `Invalid Homework Completion recordId` / `Invalid Enrollment recordId` |
