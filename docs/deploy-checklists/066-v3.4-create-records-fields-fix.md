## Why

```
Invalid arguments passed to table.createRecordsAsync(records):
records[0] should have a 'fields' property
```

**Cause:** `unlockCreatesPending` held raw field maps; `createRecordsInBatches` passed them to `createRecordsAsync` (which requires `{ fields: {...} }`). Single-create used `createRecordAsync(fields)` and worked; two or more unlocks failed.

**Fix:** Defensive normalize accepts raw maps or `{ fields }` and always calls `createRecordsAsync([{ fields }, ...])`.
