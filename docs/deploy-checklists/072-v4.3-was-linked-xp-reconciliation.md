## Problem

WAS `reczxTIpVI8ZJLex0` (Perfect Week Testing) failed 072 with:

`Weekly XP disagreement: summary=1025, active canonical XP=1260.`

**Root cause:** Shot milestone XP events (+235) were active on Enrollment+Week but not yet linked on the WAS when 072 ran. The rollup (`XP Earned This Week` = 1025) matched **linked** XP only; v4.2 compared rollup to **all** enrollment+week XP (1260) and threw a misleading disagreement.

**Current settled state (2026-08-23):** rollup = linked sum = **1260** across 40 XP Events. Email build may proceed after paste.

## Fix (v4.3)

1. Compare rollup to **WAS-linked** active XP only.
2. Fail first with **Unlinked canonical XP** when active enrollment+week events exist but are not on the WAS.
3. Clearer rollup mismatch message when linked sum ≠ rollup.
