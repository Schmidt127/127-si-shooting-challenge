## Product rule (summary)

Perfect Week daily shooting eligibility now allows legitimate delayed uploads:

1. **Activity Date** = when shooting happened (America/Denver calendar day).
2. **Submitted At** = upload timestamp (never `Created`).
3. Activity Date must not be in the future.
4. A submission qualifies when `Count This Submission? = true`, Activity Date is inside the official Sunday–Saturday week, upload occurs within the grace window, and daily shot minimum is met.
5. **Grace window** = configurable hours after end of Activity Date (default **48**).
6. Submissions beyond grace remain valid shooting submissions but do not count toward Perfect Week unless manually approved.

## Before / after behavior

| Scenario | Before (same-day only) | After (48h grace) |
|---|---|---|
| Same-day upload | Qualifies | Qualifies (`on_time`) |
| Upload 24h later, within grace | Does not qualify | Qualifies (`grace_period`) |
| Upload >48h after activity day end | Does not qualify | Does not qualify (`late`) |
| Future Activity Date | Does not qualify | Does not qualify |
| Manual exception checked | Does not qualify | Qualifies (`manual_exception`) |
| General shooting days (Count This?) | Unchanged | Unchanged |

### 2. Submissions — new formula / checkbox fields

| Field | Type | Purpose |
|---|---|---|
| `Perfect Week Submission Timing Status` | Single select (`On Time`, `Grace Period`, `Late`, `Manual Exception`, `Ineligible`) | Auditable timing bucket |
| `Perfect Week Grace Eligible?` | Formula (0/1) | Grace-window pass (excludes future dates) |
| `Perfect Week Manual Exception?` | Checkbox | Operator-approved late submission |
| `Perfect Week Countable Submission?` | Formula (update existing) | Uses grace eligibility instead of `Submitted Same Day?` |

Keep **`Submitted Same Day?`** unchanged for audit/history.

### 3. Suggested formula — `Perfect Week Grace Eligible?`

Uses `{Submission Grace Period Hours}` lookup from Achievements (or literal `48` until lookup exists):

```text
IF(
  OR(
    {Perfect Week Manual Exception?},
    AND(
      {Count This Submission?} = 1,
      {Activity Date},
      {Submitted At},
      {Activity Date} <= TODAY(),
      DATETIME_DIFF(
        {Submitted At},
        DATETIME_PARSE(
          DATETIME_FORMAT(
            DATEADD({Activity Date}, 1, 'days'),
            'YYYY-MM-DD'
          ) & ' 00:00',
          'YYYY-MM-DD HH:mm',
          'America/Denver'
        ),
        'hours'
      ) <= IF({Submission Grace Period Hours}, {Submission Grace Period Hours}, 48)
    )
  ),
  1,
  0
)
```

> Adjust lookup field names to match the approved schema. Contract tests in GitHub are the source of truth for edge behavior.

### 4. Update `Perfect Week Countable Submission?`

Replace the `Submitted Same Day? = 1` requirement with `{Perfect Week Grace Eligible?} = 1` while keeping existing Enrollment / Week / shots guards.
