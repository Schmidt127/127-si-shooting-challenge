# Automation 071 v4.1 + 020 v3.6 — PHA Grade Band metadata-only

**Date:** 2026-08-17  
**Branch:** `fix/pha-grade-band-metadata-only`  
**Symptom fixed:** Homework Completion failed 071 with `PHA Grade Band mismatch` when the linked Program Homework Assignment listed multiple Grade Bands (e.g. K-2, 3-4, 5-6, 7-8, 9-12).

## Product rule

PHA **Grade Band** is descriptive eligibility metadata. Operational match is:

```text
Program Instance + Week + Homework Assignment + Homework Slot
```

Do **not** require PHA Grade Band = Enrollment Grade Band.
